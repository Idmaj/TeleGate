# TeleGate

<img src="src/assets/icon.png" width="72" height="72" alt="TeleGate icon">

**Telegram access for AI assistants, with control over every account and action.**

TeleGate is a Windows desktop application that connects MCP-compatible assistants to personal Telegram accounts through a local HTTP server. It combines cross-chat search, message context, and Telegram account management with configurable read permissions and explicit approval for writes.

## Highlights

- **Scoped access:** allow, deny, or review reads by account, chat, folder, chat type, and operation. Permissions can expire or remain active until revoked.
- **Search and context:** search messages across permitted chats with date, sender, media, filename, and topic filters. Retrieve surrounding messages, replies, pinned messages, and discussion threads.
- **Reviewed actions:** inspect the destination, formatted content, attachments, and schedule before approving a message or account change.
- **Rich messaging:** compose formatted messages, send media and albums, reply in topics, create polls, and manage scheduled messages.
- **Multiple accounts:** manage independent Telegram sessions with optional default or per-account proxy settings.
- **Desktop controls:** review requests in a notification card or approval center, inspect decision history, and pause AI access from the application or system tray.
- **Persistent context:** maintain global and per-chat notes that accompany authorized results and help assistants follow communication and workflow preferences.

Read operations do not mark messages as read. Sending read receipts is a separate operation that requires approval.

## Getting started

TeleGate runs on Windows. Use a packaged installer or portable executable, or build it from source with Node.js 22.12 or later and npm:

```powershell
npm ci
npm start
```

1. Add a Telegram account using your own API ID and API Hash from [Telegram's developer portal](https://my.telegram.org).
2. Configure read permissions in **Rules & permissions**.
3. Copy the endpoint and token from **MCP connection** into your assistant's MCP configuration.
4. Keep TeleGate running. Closing the window leaves it available in the system tray.

| Connection setting | Value |
| --- | --- |
| Transport | MCP Streamable HTTP |
| Endpoint | `http://127.0.0.1:19741/mcp` |
| Authentication | Bearer token generated by TeleGate |

See the [setup guide](docs/getting-started.md) for account sign-in, client configuration, proxies, and upgrades.

## Access and approvals

Reads ask for approval unless a saved permission or rule authorizes them. Deny rules take precedence over ask rules, followed by allow rules. Chat discovery and cross-chat search default to the permitted workspace, so an assistant can find and use an authorized chat without requesting access to the complete directory.

Writes always require approval for the exact request. Assistants can propose changes to access rules and saved memory, but those changes require a separate review. The MCP interface does not expose an approval tool.

## Local storage and privacy

The MCP server binds to the loopback interface and requires authentication. Telegram sessions, API hashes, tokens, proxy credentials, saved memory, and persisted job records use Windows-backed Electron secure storage. Account labels, access rules, and audit metadata are stored as ordinary settings.

Information returned to an assistant is handled by that assistant and its provider. Local storage protection does not protect against malicious software running as the same Windows user. See the [security and data-handling documentation](SECURITY.md) for the trust model and deployment boundaries.

## Development

```powershell
npm test
npm run test:approvals
npm run dist -- --config.electronDist=node_modules/electron/dist
```

The build produces a Windows installer and a portable executable in `dist/`. Automated tests use synthetic fixtures; Electron UI tests use an isolated application profile. Telegram-specific privileges and network behavior still require integration testing with a dedicated test account.

## Scope

TeleGate supports personal Telegram accounts through GramJS. Telegram permissions, rate limits, and content restrictions continue to apply. Calls, Secret Chats, Stories, and bot-only inline keyboards are outside the current feature set. Windows packages are unsigned unless signing is configured by the distributor.
